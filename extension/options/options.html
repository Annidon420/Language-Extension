🔒 Zero Cloud Surveillance Guarantee

  • No browsing history, URLs, or full-page text are collected or transmitted to tracking servers.
  • DOM translation runs client-side inside the content script environment.
  • Input fields, password inputs, credit card forms, and code blocks (<pre>, <code>) are strictly excluded from extraction.

ScreenLingo AI Architecture

Real-Time Screen & Website Translator System Overview

Modules

1. Android Screen Translator:

Android 14+ MediaProjection API, Google ML Kit on-device Text Recognition (OCR), ML Kit Language Identification, on-device translation, and WindowManager overlay service.

2. Browser Extension:

Manifest V3 Service Worker, TreeWalker DOM layout-preserving translator, live MutationObserver, and selection tooltip.

3. Cross-Platform Parity:

Both applications share unified ISO-639-1 language models, strict privacy controls, and instant original/translated switching.
